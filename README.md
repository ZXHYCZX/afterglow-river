# 把余光留给你

**After the Last Light** — 一场关于爱、告别与继续生活的夜航。

一个约 5–8 分钟的原创中文浏览器叙事小游戏。划过夜河，拾起六件旧物，决定让它们的光留在身边，还是照向前路。三种结局没有好坏之分。

## 游玩

- 方向键 / WASD：划船。
- 鼠标或触屏：按住水面拖动。
- 按住空格 /「守灯」：减慢航速，抵挡冷雾。
- 靠近金色方灯：拾起回忆；小光点会补充灯火。
- Esc / P：暂停。可开启「舒缓航行」，让灯火不减。
- 回忆册保留每件旧物的文字。每次选择后在本机自动保存。

## 运行和部署

无需构建、依赖或 API key。可直接打开 `index.html`，或在项目目录运行：

```sh
python -m http.server 4317
```

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 禁用 Jekyll 处理。所有资源使用相对路径，兼容项目型 Pages 地址。

## 制作

原创新故事、Canvas 2D 航行与粒子动画。音乐使用 Web Audio 实时合成，不请求外部音频。夜河背景为本项目通过 OpenAI ImageGen 生成的原创画面。字体使用设备自带字体，无外部 CDN。无账户、无追踪、无网络数据收集。

存档仅保存在当前浏览器的 localStorage；关闭隐私窗口或清理网站数据可能移除存档。声音需要手动开启。
